# Road Damage Detection Using UAV Images

## Project Overview
This project focuses on detecting road damage such as cracks and potholes using images captured by UAV (drone) cameras.

The project compares YOLO models for road damage detection and advances the detection process using YOLOv8.

## Objectives
- Detect road damage from UAV images.
- Identify cracks and potholes.
- Compare the performance of different YOLO models.
- Improve road damage detection using YOLOv8.

## Technologies Used
- Python
- YOLO / YOLOv8
- OpenCV
- NumPy
- PyTorch
- Ultralytics

## Methodology
1. Collect road images using UAV/drone cameras.
2. Prepare and annotate the dataset.
3. Train YOLO models on the dataset.
4. Detect road damage from test images.
5. Compare model performance.
6. Evaluate the results using detection metrics.

## Applications
- Road condition monitoring
- Smart transportation
- Road maintenance planning
- Automated pothole and crack detection

## Expected Outcome
The system detects road damage automatically from UAV images and helps identify the model that provides better detection performance.
